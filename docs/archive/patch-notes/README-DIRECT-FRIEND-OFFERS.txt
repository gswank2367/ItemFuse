ItemFuse direct friend offers patch

Adds:
- Send Offer button for Steam friends who are also ItemFuse members.
- Direct friend offer builder: select one or more of your items and one or more of your friend's synced tradable items.
- Estimated value comparison before sending.
- Direct offers use the existing Offers / Trades / Alerts / Chat system.
- No public listing is created. ItemFuse creates a hidden internal direct-offer anchor only.
- Counteroffers and accepted-offer Steam handoff continue to use the existing offer flow.

Important:
- Both traders must be ItemFuse users for in-app direct offers.
- The friend must have synced tradable items in ItemFuse.
- No database migration is required.
